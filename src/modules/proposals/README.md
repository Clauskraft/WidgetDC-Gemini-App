# WidgeTDC Proposals & Reference Architecture

The `.py` files in this directory are non-runtime architectural proposals and reference material for the OpenWebUI framework and python-based integration environments.
They are NOT executed by the AI Studio TypeScript/Vite runtime.

They represent planned modules for:
- Connecting NotebookLM natively.
- Operating the Gemini Live Audio/Video API.
- Structuring the Agentic MCP calls.
- Routing via the Omega Sentinel.
- Establishing a Neo4j GraphRAG context baseline.
